# Plans and implementation records

This directory keeps engineering plans and verification notes. These documents capture scope and decisions; they are not deployment instructions.

- `001`–`012` — UI motion and interaction polish plans. Their original status table records all twelve as complete.
- [014 — Persistent chat tools rail](014-chat-tools-rail.md) — product specification; still has unimplemented acceptance items.
- [015 — New-chat and asset bug scan](015-bug-scan-and-fix-plan.md) — implemented fixes and verification limits.
- [016 — Follow-up bug scan](016-post-implementation-bug-scan.md) — scroll behavior, asset promotion, regression checks, and rollout status.

For current setup and commands, see the root [README](../README.md). For behavior and security boundaries, see [ARCHITECTURE.md](../ARCHITECTURE.md). Older roadmaps are in [docs/archive](../docs/archive/README.md).
