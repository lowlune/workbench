# Archív starých plánov

Tieto súbory sú **historické snapshoty** z 5. – 6. 10. 2026. Každý napísal iný
agent/beh, preto sa čiastočne duplikujú a sú zastarané. **Nie sú zdrojom pravdy.**

Aktuálny stav a plán:
- `../../PLAN.md` — jediný aktuálny plán
- `../../ARCHITECTURE.md` — čo reálne existuje
- `../../TODO-FIX.md` — fix checklist (hotový)

Obsah archívu:
- `PLAN.md` — pôvodný „Pi-first refactor" (Fáza 1+2). Jeho acceptance je dnes
  pokryté `scripts/workbench.acceptance.mjs`.
- `PLAN-VERTICAL-TABS.sk.md` — plán vertikálneho pruhu tabov (v kóde sú referencie
  `PLAN-VERTICAL-TABS §x`; reálne je implementovaný horizontálny pruh).
- `PLAN-HOSTING.sk.md` — varianty exposície/nasadenia; rozhodnutie ešte otvorené.
- `WORKBENCH-PRODUCTION-PLAN.sk.md` — veľký audit + produkčná roadmapa (Fáza 0–6).
- `WORKBENCH-V3-PLAN.sk.md` — ďalšia roadmapa prestavby (Fáza 0–7); delta k produkčnému plánu.
